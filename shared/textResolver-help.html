textResolver.js

Libreria shared per la risoluzione di placeholder dinamici nei testi

1. Import

const { resolveText, formatDate } = require('../shared/textResolver');

2. Funzioni esportate

resolveText(text, vars?, opts?)

Sostituisce tutti i [[...]] nel testo con i valori calcolati.

textStringa con placeholder
varsOggetto chiave-valore per variabili custom
opts.nowDate iniettabile (per test)

return Stringa con placeholder risolti

formatDate(date, format?)

Formatta una Date nativa secondo un pattern di token.

dateOggetto Date
formatPattern (default YYYY-MM-DD)

return Stringa formattata

3. Sintassi dei placeholder

Ogni placeholder ha la forma: [[keyword+offset,FORMAT]]

Offset e formato sono opzionali.

Keyword date

Supportano offset (+N / -N) e formato opzionale dopo la virgola.

KeywordSignificatoFormato default
todayData odiernaYYYY-MM-DD
yesterdayAlias per today-1YYYY-MM-DD
tomorrowAlias per today+1YYYY-MM-DD
nowDatetime correnteISO 8601
lastBusinessDayUltimo giorno lavorativo (lun-ven). L'offset conta in business day, non giorni di calendario.YYYY-MM-DD

Keyword speciali

KeywordSignificatoEsempio output
timestampUnix epoch in secondi1738950000
uuidIdentificativo univoco UUID v4a3f1b2c4-d5e6-4f7a-...
env:NOME_VARValore di process.env.NOME_VAR(valore della variabile o stringa vuota)

Token di formato

TokenDescrizioneEsempio
YYYYAnno 4 cifre2026
MMMese 2 cifre02
DDGiorno 2 cifre07
HHOre 24h14
mmMinuti30
ssSecondi05

4. Esempi

Data base

resolveText('Oggi: [[today]]')
// => "Oggi: 2026-02-07"

resolveText('Ieri: [[yesterday]]  Domani: [[tomorrow]]')
// => "Ieri: 2026-02-06  Domani: 2026-02-08"

Formato custom

resolveText('Scadenza: [[today,DD/MM/YYYY]]')
// => "Scadenza: 07/02/2026"

resolveText('[[now,YYYY-MM-DD HH:mm:ss]]')
// => "2026-02-07 14:30:00"

Offset giorni

resolveText('Tra 30 giorni: [[today+30,DD/MM/YYYY]]')
// => "Tra 30 giorni: 09/03/2026"

resolveText('Una settimana fa: [[today-7]]')
// => "Una settimana fa: 2026-01-31"

resolveText('3 giorni prima di ieri: [[yesterday-3]]')
// => "3 giorni prima di ieri: 2026-02-03"

Variabili custom

resolveText(
  'Report [[symbol]] dal [[today-7]] al [[today]]',
  { symbol: 'AAPL' }
)
// => "Report AAPL dal 2026-01-31 al 2026-02-07"

Data iniettata (per test)

resolveText(
  '[[today]] [[yesterday]]',
  {},
  { now: new Date('2025-12-25') }
)
// => "2025-12-25 2025-12-24"

lastBusinessDay

resolveText('Ultimo close: [[lastBusinessDay]]')
// => "Ultimo close: 2026-02-06"  (se oggi e' sabato/domenica, arretra a venerdi)

resolveText('5 sedute fa: [[lastBusinessDay-5,DD/MM/YYYY]]')
// => "5 sedute fa: 30/01/2026"  (offset in business day, salta weekend)

timestamp e uuid

resolveText('Epoch: [[timestamp]]')
// => "Epoch: 1738950000"

resolveText('Job ID: [[uuid]]')
// => "Job ID: a3f1b2c4-d5e6-4f7a-8b9c-0d1e2f3a4b5c"

Variabili d'ambiente

resolveText('Host: [[env:DBMANAGER_URL]]')
// => "Host: http://dbmanager:3002"

resolveText('Env: [[env:NODE_ENV]]')
// => "Env: production"

Esempio completo

resolveText(
  'Job [[uuid]] avviato il [[now,YYYY-MM-DD HH:mm:ss]] - dati dal [[lastBusinessDay-5]] al [[lastBusinessDay]] per [[symbol]]',
  { symbol: 'MSFT' }
)
// => "Job a3f1...5c avviato il 2026-02-07 14:30:00 - dati dal 2026-01-31 al 2026-02-06 per MSFT"

formatDate standalone

formatDate(new Date(), 'DD/MM/YYYY HH:mm')
// => "07/02/2026 14:30"

5. Comportamento

safe

Placeholder non riconosciuti

Restano invariati nel testo. Non viene lanciato nessun errore.

resolveText('[[foo]]')
// => "[[foo]]"

safe

Input non stringa

Viene restituito invariato senza errori.

resolveText(null)  // => null
resolveText(42)    // => 42

nota

Formato vuoto

[[today,]] con virgola ma formato vuoto usa il default YYYY-MM-DD.

offset composti

yesterday/tomorrow + offset

Gli offset si sommano all'alias.

[[yesterday-2]]  // today - 3
[[tomorrow+5]]   // today + 6
