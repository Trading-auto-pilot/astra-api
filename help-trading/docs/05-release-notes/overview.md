# Release Notes

Questa sezione raccoglie le release notes ufficiali con un formato standard unico per ogni rilascio.

## Formato standard pagina release

Ogni pagina deve contenere sempre:

1. Numero release globale (frontend `astraai/public/release.json -> version`)
2. Data rilascio globale (frontend `astraai/public/release.json -> lastUpdate`)
3. Tabella riepilogo versioni backend (per microservizio)
4. Modifiche di dettaglio per ogni componente backend
