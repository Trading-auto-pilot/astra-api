# Endpoint dettagliati

## Endpoint business

Consultare le route del servizio sotto prefisso:

- `/datahub`

## Endpoint standard microservizio

- `GET /datahub/release`
- `GET /datahub/settings`
- `PUT /datahub/settings`
- `POST /datahub/settings/reload`
- `PUT /datahub/connect`
- `DELETE /datahub/connect`
- `GET /datahub/dbLogger`
- `PUT /datahub/dbLogger/:status`

## Endpoint status

- `GET /datahub/status/health`
- `GET /datahub/status/info`
- `GET /datahub/status/metrics`
- `GET /datahub/status/logLevel`
- `PUT /datahub/status/logLevel`
- `GET /datahub/status/communicationChannels`
- `PUT /datahub/status/communicationChannels`
