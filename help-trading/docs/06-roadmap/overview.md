# Roadmap

Questa sezione raccoglie note e piani per sviluppi futuri del sistema. Non si tratta di impegni formali di rilascio, ma di analisi tecniche, proposte di miglioramento e bozze di architettura pensate per guidare le prossime iterazioni.

Ogni pagina descrive:

- Il **contesto attuale** del componente o funzionalità coinvolta
- Il **problema o gap** che si vuole risolvere
- Un **piano tecnico** con le modifiche proposte, i prerequisiti e i rischi
